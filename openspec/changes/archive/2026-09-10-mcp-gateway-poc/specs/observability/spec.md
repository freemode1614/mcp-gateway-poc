## ADDED Requirements

### Requirement: Structured JSON logging with request_id

The gateway SHALL emit one JSON object per log line and propagate a `request_id` across all log events generated by the same inbound request.

#### Scenario: Tool call log shape

- **WHEN** a client calls `tools/call` and the gateway processes it
- **THEN** the gateway emits at least one log line with `event = "tool_call"`, `request_id`, `backend`, `tool`, `args_size_bytes`, `duration_ms`, and `status` (`ok` or `error`)

#### Scenario: Related logs share request_id

- **WHEN** a single inbound request triggers multiple log events (start, backend call, completion, error)
- **THEN** every event for that request carries the same `request_id`

#### Scenario: request_id is generated per request

- **WHEN** the gateway receives an inbound request without a client-provided `X-Request-ID` header
- **THEN** the gateway generates `request_id = "req_" + 8 hex chars from uuid4`

#### Scenario: Client-supplied request_id is honored

- **WHEN** the client sends an `X-Request-ID` header
- **THEN** the gateway uses that value as the request_id (after validating it is a non-empty string ≤ 128 chars)

#### Scenario: Lifecycle events are logged

- **WHEN** the gateway starts, a backend connects or disconnects, or a reload is applied
- **THEN** the gateway emits a structured log with a distinct `event` field (`startup`, `backend_connected`, `backend_disconnected`, `reload_applied`, `config_error`)

### Requirement: Health endpoint reports per-backend status

The gateway SHALL expose `GET /health` (outside the MCP SSE stream) that returns the status of each backend and an overall HTTP status code.

#### Scenario: All backends healthy

- **WHEN** `GET /health` is called and every backend is `healthy`
- **THEN** the response is `200 OK` with body `{"status": "ok", "backends": {"<name>": "ok", ...}}`

#### Scenario: Some backends unhealthy

- **WHEN** `GET /health` is called and at least one backend is not `healthy` but at least one is `healthy`
- **THEN** the response is `200 OK` with body `{"status": "degraded", "backends": {"<name>": "ok" | "unhealthy" | "permanently_failed", ...}}`

#### Scenario: All backends down

- **WHEN** `GET /health` is called and every backend is not `healthy`
- **THEN** the response is `503 Service Unavailable` with `{"status": "down", ...}`
